I'm **Albara Fahed Alharissy**, an Information Technology student at **Al-Jazeera University** and a Junior **C# / .NET Backend Developer**.

I focus on building maintainable backend applications, designing RESTful APIs, working with relational databases, and implementing business logic.

- Developing RESTful APIs using **ASP.NET Core Web API**.
- Working with **SQL Server**, **Entity Framework Core**, and database design.

- Student management operations.
- JWT Authentication.
- Access and Refresh Tokens.
- Role-Based and Ownership-Based Authorization.
- Login Rate Limiting.
- BCrypt Password Hashing.
